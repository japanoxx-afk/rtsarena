# 라크무(new-rakum) 쪽에 필요한 수정 — 요청서

전적 사이트는 **지금 상태의 라크무 서버·런처로도 동작한다.** 아래는 정확도를 높이기 위한 수정이며,
아직 new-rakum 저장소에는 아무것도 바꾸지 않았다. 우선순위 순.

현재 데이터 흐름:
```
경기 종료 → 런처 replay_recorder 가 replays/*.rkr 저장
          → arena_upload.py 가 사람 2명 이상이면 NAS rtsarena-web 로 POST
rtsarena-web → .rkr 해석(맵·종족·시간·참가자) + 로비 서버 matches.json 에서 같은 경기 찾아 승패·상대 이름 보충
```

## A. 런처 리플레이 기록 (replay_recorder.py / replay_memory.py) — 필수에 가까움

1. **상대 플레이어 이름이 비어 있음** — 실제 대전 리플레이(2026-11-21 03:08 `[2]Distant`)의 머리:
   `slots=[32,32]`, `players=[{"index":0,"name":"aa"}]` → 상대(1번)의 이름이 메모리 `플레이어 구조 +8` 에서 빈 문자열.
   `Recorder.poll()` 의 `active = [p.index for p in players if p.active and p.name]` 때문에 상대가 빠진다.
   - 해야 할 것: 원격 플레이어 이름이 실제로 있는 메모리 위치를 찾아 머리에 넣기 (방 멤버 목록 등).
   - 그동안은 사이트가 로비 서버 기록으로 이름을 채운다. 로비 서버 기록이 없으면 그 경기는 **거절**된다.
2. **경기 결과(승/패)를 리플레이에 기록** — 끝날 때 결과(로비 서버에 보내는 0x24FF 결과코드와 같은 값)를
   마지막 줄에 `{"result": {"code": 1}}` 처럼 남기면, 로비 서버 결과가 늦거나 없어도 승패가 정확해진다.
   지금은 로비 서버 결과가 없으면 "마지막 장면에 건물이 남은 사람 1명 = 승"으로 **추정**한다.
3. **slots 값 의미 확정** — 사이트는 `0x20=사람, 0x10=컴퓨터` 로 본다(실제 리플레이 4개로 확인: 싱글 3개는 [32,16],
   대전 1개는 [32,32]). 팀전·관전자·나간 사람 값이 다르면 알려 줄 것.
4. (선택) 머리에 `"server_match_id"` (아래 B-1) 와 `"lobby_account"` (로그인 계정) 를 넣으면 대조가 확실해진다.

## B. 로비 서버 (server.py, NAS rakmu-server 컨테이너)

1. ~~**경기 ID**~~ — **완료 (서버 0.9017)**: 기록마다 `"id"`. 사이트는 이것을 경기 키로 쓴다.
2. ~~**기록 500개 제한**~~ — **완료 (서버 0.9017)**: 전부 보관. 게임 안 랭킹과 사이트 리더보드가 같은 전체 기록을 본다.
3. **종족·팀**: 방에서 고른 종족·팀을 서버가 알 수 있으면 기록에 추가 (지금은 리플레이에서만 가져온다).
4. **끝난 시각·경기 시간**: 0x24FF 를 받은 시각을 `results[계정]["at"]` 에 남기면 중도 이탈 판정에 도움.
5. ~~파일 동시 쓰기~~ — **완료 (서버 0.9017)**: 임시 파일에 쓰고 `os.replace`. 깨진 파일은 `matches.json.bad-<시각>` 으로
   옮겨 두고 새로 시작 (예전엔 빈 목록으로 덮어써 전체 기록을 잃을 수 있었음).

## C. NAS 배포

- 새 스택 `rtsarena` (deploy/compose.yaml), 포트 VM 30013 → 컨테이너 8080. 30013 이 비어 있는지 Portainer 에서 확인.
- 공유기는 30000~30999 를 VM 으로 전달한다고 기록돼 있음(new-rakum nas-server/ports.txt) → 외부에서
  `http://112.159.73.235:30013` 으로 열리는지 확인 필요. 다른 포트라면 런처 `ARENA_URL` 도 바꾼다.
- 리플레이 보관 용량: 대전 1판 약 50~200KB. 1만 판 ≈ 1~2GB. `data/replays/rakmu/YYYYMM/` 로 나뉜다.
